**KAINOapp** — це зручний, персональний локальний клієнт-помічник (PC Desktop + Mobile) для студентів **Цифрового університету КАІ** (`cabinet.kai.edu.ua`).

---

## 📌 Відмова від відповідальності (Disclaimer)

- **Неофіційний клієнт**: KAINOapp є незалежним студентським відкритим проєктом і не є офіційним програмним забезпеченням університету КАІ.
- **Права на дані**: Всі торгові марки, назви дисциплін, логотипи та дані розкладу належать їх законному власнику — Цифровому університету КАІ.
- **Приватність**: Застосунок не збирає, не передає та не зберігає облікові дані або розклад на жодних сторонніх серверах. Всі запити відбуваються безпосередньо з пристрою користувача.

---

## 🛡 Захист та Безпека Даних

1. **🔒 100% Локальне збереження (Local-First)**:
   Ваші логін та пароль зберігаються виключно в захищеному пам'яті вашого смартфона/ПК.
2. **📖 Відкритий код (Open Source Trust)**:
   Весь код повністю відкритий для аудиту будь-яким студентом чи викладачем.
