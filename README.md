**KAINOapp** — це сучасний, швидкий та безпечний кросплатформений застосунок (PC Desktop + Mobile) для студентів **Цифрового університету КАІ** (`cabinet.kai.edu.ua`).

---

## 🛡 Захист та Безпека Даних (100% Open-Source & Private)

1. **🔒 100% Локальне збереження (Local-First Architecture)**:
   Ваші паролі та персональні дані **НІКОЛИ не передаються на сторонні сервери або хмари**. Всі запити йдуть виключно напряму між вашим пристроєм та офіційним порталом `cabinet.kai.edu.ua`.
2. **📖 Відкритий вихідний код (Open Source Trust)**:
   Весь код повністю відкритий для перевірки будь-яким студентом чи факультетом. Ви особисто можете пересвідчитись у відсутності прихованих трекерів чи загрози витоку даних.
3. **🚀 Автоматичне незгораєме сховище (Double-Layer Persistence)**:
   Присутній резервний захист даних на вашому диску (`local_user_data.json`). Навіть після очищення кэшу браузера розклад зберігається.

---

## ✨ Основні Можливості

- 📅 **Динамічний 7-денний Календар**: Автоматичний вивід пар на ближайші 7 днів з урахуванням дати пристрою.
- 🔄 **Авто-синхронізація розкладу**: Автоматичне фонове оновлення раз на годину та при кожному вході.
- 💻 **Швидкий перехід у MS Teams**: Прямі кнопки входу на онлайн-парах.
- 📊 **Сесія та Оцінки**: Моніторинг підсумкових балів, заліків та розкладу сесії.
- 🛠 **Студентські Сервіси**: Інформація про Обхідний лист, Вибіркові дисципліни, Кваліфікаційні роботи та Опитування.
- 🚀 **Авто-Оновлення в 1 клік**: На ПК застосунок оновлюється напряму з офіційного GitHub репозиторію.
